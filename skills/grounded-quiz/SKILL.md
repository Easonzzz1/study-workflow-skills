# Create a grounded practice quiz

Confirm the source scope, question count, format, difficulty, and language. If a requested format needs information absent from the sources, explain the gap and ask whether an explicitly labeled supplement is wanted. Do not invent supporting source content.

Cover concept boundaries, method selection, and application. Make distractors reflect plausible mistakes. State all information needed for calculation questions: data, units, conventions, required precision, and relevant assumptions. Multi-select questions must be labeled clearly, with an unambiguous set of correct choices.

Present questions first and place the answer key afterwards unless the user requests another learning mode. For each answer, explain the reasoning, reject distractors individually, and cite a verified source section or page. Recompute all numerical answers independently; reconcile any discrepancies with the source before delivering.

Label questions as original, adapted, or quoted, and respect source rights. Newly generated questions are practice, never a past paper or evidence of likely exam content. If a target tool supports only choice questions, adapt the presentation while retaining the reasoning in the answer explanation.

End with review advice by error type, linked to actual source sections. Preserve uncertainty when a source or answer cannot be checked. A full question count alone does not establish quiz quality.
