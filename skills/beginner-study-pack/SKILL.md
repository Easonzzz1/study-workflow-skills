# Build a beginner study pack

Establish the included source units, excluded topics, learner's starting knowledge, language, and output format. Do not infer exam rules or extend the lecture range from unrelated source files. Inspect source text before teaching it; label unreadable or missing sections.

Teach each concept through a concrete problem, intuitive example, definition with useful original-language terms, worked application, and common mistake. Introduce mathematical prerequisites when needed. Show why a formula applies, define its symbols, substitute values, retain intermediate steps, and interpret the result.

Keep course-specific conventions explicit. Independently recompute numerical examples. If the source and recomputation disagree, show both and explain the difference rather than silently changing the source. Do not generalize a convention from one course to another.

Distinguish source examples, adapted exercises, and newly written explanations. Cite only inspected page/section locations. For Markdown or unpaginated text, cite headings; never invent page numbers. Do not claim that a topic is guaranteed to appear on an exam.

For paper use, provide a formula lookup, keyword index, and calculation checks with legible monochrome layout. If space is constrained, split the pack into modules instead of deleting essential reasoning. Report any unresolved source or calculation gaps.
