# Source-grounded concept maps

Use the user's chosen sources and scope. First identify concepts, prerequisites,
mechanisms and exceptions; distinguish a hierarchy from causal or cross-branch
links. Label each relationship with its meaning. Do not turn an association into
causation, or an example into a general rule. Keep unsupported links visibly
unverified. A citation belongs to the actual readable location, not a guessed page.

Prefer short node titles with concise notes and source locations. Separate
similar terms explicitly when their distinction matters. Let the learner move
nodes without changing the meaning of edges. Explain remaining ambiguities.

For a local editable result, use the repository's
[offline concept map](../../tools/concept-map/index.html). Its JSON schema is in
[the tool guide](../../docs/CONCEPT_MAP.md). Generate only the bounded graph data
and review it before importing. Do not copy source files into the tool or encode
raw institutional/student information. The tool formats a graph; it does not
validate scientific claims or automatically read sources.

Verify the requested interactions and exported/reimported data when a browser
is available. Distinguish data validation, observed browser behavior and content
accuracy in the completion report. Keep private source material out of public
repositories; use synthetic examples for contributions.
